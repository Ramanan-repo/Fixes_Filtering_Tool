# Fixes_Filtering_Tool
### Fixes Filtering Tool – Electron Desktop Application

**Project Description:**

The Fixes Filtering Tool is a desktop application developed using the Electron framework to help QA testers extract and identify ticket IDs (Fix IDs) from Jenkins Console Output.

**Technologies Used:**
- **Electron:** Framework for building cross-platform desktop applications.
- **HTML:** Frontend structure and UI.
- **CSS:** UI styling and design.
- **JavaScript:** Application logic for filtering and extracting Fix IDs.

**Working:**

The tool extracts Fix IDs from the `index.html` page containing Jenkins Console Output and displays the filtered results in `result.html`. QA testers can use these Fix IDs to identify fixes and perform retest validation.

**Objective:**

To reduce manual effort and save testing time by automating the process of identifying Fix IDs from Jenkins Console Output.
